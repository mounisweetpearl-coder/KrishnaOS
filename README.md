# 🖥️ KrishnaOS v1.0.4

**KrishnaOS** is a secure, lightweight terminal-based operating system simulation built entirely in C. It features a robust security gate, persistent storage, and built-in utilities for a complete terminal experience.

---

## 🚀 Key Features

*   **Secure Authentication**: Masked PIN entry (******) with a 3-attempt lockout system for maximum security.
*   **Persistent Wallet**: A built-in Casino game with a wallet that saves your balance to `balance.txt`. Your progress stays with you!
*   **Notepad**: Create, save, and access private notes with password protection.
*   **System Utilities**: Built-in high-precision calculator, system clock (`date`), and environment clearing.
*   **Legal Security**: Full system information and copyright notices baked into the kernel.

---

## 🛠️ Installation & Usage

Since this is a proprietary build, the source code is currently **Closed Source**. To run KrishnaOS on your Windows machine:

1.  Go to the **[Releases](link-to-your-github-releases)** section of this repository.
2.  Download the `KrishnaOS.exe` file.
3.  Open your terminal or command prompt.
4.  Run the file: `.\KrishnaOS.exe`

*Note: Default system PIN is required for access which is 130513.*
